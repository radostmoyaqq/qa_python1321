# qa_python

Проект содержит тесты для класса `BooksCollector`.

## Реализованные проверки

- добавление двух книг в словарь;
- невозможность добавить книгу с пустым названием или названием длиннее 40 символов;
- невозможность добавить одну и ту же книгу дважды;
- у новой книги жанр остается пустым;
- установка корректного жанра существующей книге;
- жанр не устанавливается для неизвестной книги или несуществующего жанра;
- получение списка книг с конкретным жанром;
- книги с возрастным рейтингом не попадают в список книг для детей;
- добавление существующей книги в избранное без дублей;
- удаление книги из избранного.

## Запуск тестов

```bash
pytest -v tests.py
```
